# Online Retail Sales Analysis

## Project Overview

This project was developed as part of the Year 4 Data Visualisation and Communication module at CCT College Dublin.

The project analyses a real-world online retail dataset from a gift wholesaler. The main purpose is to transform transactional data into meaningful visual insights that can support business decisions and help managers understand sales performance, customer behaviour and market trends.

## Project Objectives

- Assess the quality of the dataset and identify potential data issues.
- Clean and prepare the data for analysis.
- Explore sales performance across products, customers and countries.
- Identify revenue trends and purchasing patterns.
- Create clear and informative static visualisations.
- Develop an interactive dashboard to support business decision-making.
- Communicate key findings, recommendations and limitations.

## Dataset

The Online Retail dataset contains transactional information, including:

- Invoice number
- Stock code
- Product description
- Quantity
- Invoice date
- Unit price
- Customer ID
- Country

The dataset was provided through the module's Moodle page.
